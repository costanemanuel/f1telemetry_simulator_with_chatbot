
# 🏎️ F1 Telemetry Simulator with Chatbot

A Java-based real-time telemetry simulation system combined with an interactive chatbot designed to process, analyze, and interact with live Formula 1 data metrics. 

This project was built as an advanced application to simulate high-frequency race telemetry, manage persistent data logging, and provide a conversational interface for real-time race insights.

---

## ✨ Key Features

* **Real-Time Telemetry Simulation:** Simulates live car metrics (such as speed, throttle, braking, gear selection, and RPM) mirroring real-world Formula 1 data streams.
* **Interactive Chatbot Integration:** A built-in chat assistant capable of answering queries regarding race data, vehicle status, and historical logs.
* **Database Management:** Uses local data persistence (`SQLite` / JDBC) to log telemetry frames, session states, and driver stats securely.
* **Modular Architecture:** Built following clean object-oriented design principles in Java, structured for scalability and easy maintenance.
* **Maven Support:** Fully configured with `pom.xml` for clean and seamless dependency management.

---

## 🛠️ Built With

* **Language:** Java
* **Build Tool:** Apache Maven
* **Database & Persistence:** SQLite / Relational Database Management
* **Environment:** IntelliJ IDEA

## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed on your machine:
* Java Development Kit (JDK 17 or higher recommended)
* Apache Maven
* IntelliJ IDEA (or any other preferred Java IDE)

### Running the Project
1. Clone the repository:
   ```bash
   git clone [https://github.com/costanemanuel/f1telemetry_simulator_with_chatbot.git](https://github.com/costanemanuel/f1telemetry_simulator_with_chatbot.git)

```

2. Open the project folder in **IntelliJ IDEA**.
3. Let Maven import all dependencies automatically from the `pom.xml` file.
4. Locate the main class (e.g., `Main.java` or `AppStarter.java`) inside `src/main/java`.
5. Run the application to start the telemetry simulation and interact with the chatbot!
